# 网文 AI 重灾区黑名单与大白话替换词库（AI-Novel Dictionary）

本词库收录了大语言模型（Claude / GPT / DeepSeek / Gemini 等）在创作中文网络小说时最高频出现的**生僻字、伪文青酸词、反人类量化、五官成精动作、欧美翻译腔及段末套话**，并提供符合**起点中文网、番茄小说**爆款爽文习惯的大白话与具象动作替换方案。

> **使用原则**：以下词表并非机械的“一刀切违禁词”，而是高频 AI 味预警信号。当这些词密集出现或造成阅读阻滞时，应优先使用右侧的“网文大白话/动作化替换方案”。

## 一、 生僻字与伪文青酸词替换表（零阅读门槛）

网文读者在手机端快速阅读，看到需要反应半秒或拿不准读音的书面词会直接跳戏。

| AI 高频生僻词/书面酸词 | 为什么有 AI 味 / 阅读痛点 | 起点/番茄大白话与动作化替换方案 |
| :--- | :--- | :--- |
| **氤氲**（yīn yūn） | 90% 的 AI 写茶水、雾气、热气必用此词 | 飘着热气、冒着白烟、雾蒙蒙、水汽弥漫 |
| **摩挲**（mó suō） | AI 写手部动作头号高频词，主角摸啥都摩挲 | 摸了摸、搓着、手指头敲着、转着手里的……、顺了顺 |
| **桎梏**（zhì gù） | 论文/公文腔重，不像小说人物或叙事的语言 | 枷锁、捆住手脚、条条框框、束缚、死规矩 |
| **诘问**（jié wèn） | 极度书面化，口语叙事几乎不用 | 质问、逼问、冷声反问、追问、呛声道 |
| **睥睨**（pì nì） | 古早装逼词，AI 写高位者看人必用 | 斜眼扫去、正眼都不瞧、居高临下盯着、冷眼打量 |
| **嗫嚅**（niè rú） | 读者常读错音，影响快节奏阅读体验 | 支支吾吾、嘴唇哆嗦、半天憋不出个屁、吞吞吐吐 |
| **踟蹰 / 踯躅** | 字典级书面词，严重拖慢网文阅读节奏 | 犹豫、磨蹭、迈不开步子、在原地打转、拿不定主意 |
| **龃龉**（jǔ yǔ） | 极冷僻书面词，网文完全不需要 | 矛盾、不对付、梁子、过节、闹掰了 |
| **藩篱**（fān lí） | 公文/评论高频词 | 界限、门槛、障壁、老规矩 |
| **裹挟**（guǒ xié） | AI 写狂风、气势、情绪必用“裹挟着” | 夹杂着、卷起、带着、混着、推着 |
| **斑驳**（bān bó） | AI 写光影、墙壁、岁月痕迹必用“斑驳” | 掉漆的、坑坑洼洼的、碎碎的树影、上了年头的 |
| **葳蕤 / 旖旎** | 矫揉造作的伪古风词 | 茂盛、枝繁叶茂 / 风光撩人、暧昧、柔和 |
| **痉挛**（jìng luán） | 医学说明书味太重 | 抽筋、直哆嗦、打摆子、猛地一抽搐 |
| **眼睑 / 瞳仁 / 颌骨** | 法医解剖报告既视感 | 眼皮、眼珠子、下巴、腮帮子 |
| **嘴角噙着（一抹笑）** | 伪文青女频/男频通病，酸气冲天 | 挂着笑、似笑非笑、带着几分笑意、憋着笑 |
| **置若罔闻 / 充耳不闻** | 成语堆砌感 | 权当没听见、左耳朵进右耳朵出、理都没理 |

## 二、 反人类时间感知与游标卡尺量化替换表

人类在打斗、震惊或日常对话中，绝不会用秒表和量角器去丈量世界。

| AI 反人类时间/量化表达 | 为什么离谱 | 起点/番茄活人感替换方案 |
| :--- | :--- | :--- |
| **足足愣了三秒钟 / 死寂了五秒** | 没人会在发呆时心里默数“一、二、三” | 愣了好半天、一时没反应过来、全场鸦雀无声、半晌才回过神 |
| **停顿了 0.5 秒 / 两秒半后** | 像机器人在按代码设定的 sleep() 延时说话 | 顿了一下、话音微顿、吸了口气接着说、略一琢磨 |
| **万分之一秒内 / 0.001 秒间** | 理科微观时间词，毫无武侠/玄幻/动作画面感 | 电光石火间、眨眼工夫、连眼皮都来不及眨、话音未落、刀尖刚沾着衣角 |
| **三分薄凉、三分讥诮、四分漫不经心** | 经典“扇形统计图”眼神，网文头号毒点 | 皮笑肉不笑、眼神冷飕飕的、压根没拿正眼看他、满脸嘲弄 |
| **七分忌惮夹杂着三分贪婪** | 情绪数字化配比，机械呆板 | 既眼馋那件宝贝，又怕自己有命拿没命花，眼神直闪 |
| **嘴角上扬三十度 / 四十五度** | 量角器成精，画面极度诡异 | 咧嘴一笑、挑了挑嘴角、露出个意味深长的笑 |
| **距离咽喉仅有 0.01 公分/厘米** | 游标卡尺式打斗，古风文里出现公分更出戏 | 刀尖已经顶得喉咙皮肤生疼、再往前一寸就能扎穿喉管、贴着脖颈寒毛停住 |
| **体内的力量暴涨了 2.5 倍** | 除系统数据流外，叙事中出现小数倍极其出戏 | 浑身力气轰然暴涨、气血翻涌得骨头节都在噼啪爆响 |

## 三、 五官与生理器官“机械成精”替换表

AI 写人物情绪，翻来覆去只有“瞳孔、嘴角、喉结、指节、冷汗”五件套。

| AI 五官/生理机械套路 | 出现频率与问题 | 具象化动作与网文替换方案 |
| :--- | :--- | :--- |
| **瞳孔猛地一缩 / 瞳孔骤缩 / 瞳孔地震** | AI 写震惊必用，一章能缩十几次 | 脸色唰地变了、猛地抬头、手里的杯子差点没拿稳、倒退了半步、眼珠子差点瞪出来 |
| **眼底闪过一抹不易察觉的寒芒/精光** | 既然“不易察觉”，视角人物是怎么看到的？ | 不动声色地垂下眼皮、心里起了杀心、面上笑着手却按在了刀柄上 |
| **嘴角勾起一抹（邪魅/玩味/似笑非笑的）弧度** | AI 味最浓的标志性短语，没有之一 | 嗤笑一声、气乐了、冷笑、似笑非笑地睨了他一眼、眉梢一挑 |
| **喉结上下艰难地滚动了一下** | AI 写紧张/害怕必滚喉结 | 咕咚咽了口唾沫、嗓子眼发干、半天没敢吭声 |

| **指甲深深嵌进掌心肉里，渗出血丝** | 自残式愤怒，无论男女老少生气都掐自己手心 | 气得浑身发抖、一口气堵在胸口、恨不得当场扑上去撕了他 |
| **后背瞬间惊出一层密密麻麻的冷汗** | 密集恐惧症式流汗 | 后脖颈子一阵发凉、汗毛倒竖、半截身子都凉了 |

| **声音沙哑得像砂纸摩擦 / 破旧风箱** | AI 写虚弱或低沉声音的唯一比喻 | 嗓子哑得几乎听不清、声音又干又涩、压低了嗓门冷冷开口 |

## 五、 段末/章末强行升华与旁白套话清剿表

AI 极喜欢在一段结束或一章结尾切换成“纪录片解说员”或“人生哲理导师”。

| AI 常见段末/章末套话 | 处理方式与网文黄金断章改法 |
| :--- | :--- |
| **“他知道，从这一刻起，命运的齿轮开始悄然转动……”** | **直接删除**，改为角色迈步离开的具体动作，或一个突发的具体小事件（如手机响起、远处传来破空声）。 |
| **“殊不知，一场席卷整个XX的惊天风暴正在黑暗中悄然酝酿。”** | **改为具体悬念**，例如写出反派此刻正在下达的具体追杀令，或主角手里攥着的底牌。 |
| **“这不仅是一场实力的较量，更是一场心理与人性的博弈。”** | **直接删除**，让打斗和算计本身展示博弈，绝不用旁白替读者总结中心思想。 |
| **“在这个弱肉强食的世界里，唯有强者才能掌控自己的命运。”** | **转化为角色台词或行动**，如主角擦净刀上的血，冷笑一句：“技不如人，怨不得旁人。” |
| **“而这一切，才刚刚开始……”** | **改为具体下一步目标**，如主角抬头看向远处的内门山峰：“下一个，就轮到赵家了。” |
| **“他的心中五味杂陈，有震惊，有苦涩，但更多的是坚定。”** | **改为动作细节**，如他仰头灌了一大口烈酒，重重顿下酒碗，转身大步流星走了出去。 |
