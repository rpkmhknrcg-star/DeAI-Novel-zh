# DeAI-Novel-zh（中文网文去 AI 味精修 Skill）

**DeAI-Novel-zh** 是一款专为**起点中文网、番茄小说、晋江文学城**等中文网络小说创作者打造的 Agent Skill（支持 Claude Code、Google Antigravity、Cursor 等 AI 编程/写作助手）。

本项目结构参考自 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)，但针对**网络小说与论文/非虚构写作的本质差异**进行了彻底重构。

---

## 💡 为什么网文不能直接用普通“去 AI 味”工具？

通用的文章去 AI 味工具（如原版 Humanizer）遵循的是**“论文/公文极简原则”**——砍掉一切修饰、合并重复情绪、删光铺垫，结果往往把一章 3000 字的网文直接压缩成 800 字的**故事梗概（大纲文）**。

而在起点、番茄等网文平台中：
- 论文里看来的“废话”（如**路人震惊捧哏、装逼打脸前的铺垫拉扯、主角内心吐槽算计、环境压迫感烘托、章末断章钩子**），恰恰是网文推进剧情、拉满爽感与维持日更字数的**核心命脉**。
- 网文真正需要去除的“AI 味”，是**阅读阻力（生僻字/伪文青酸词）**、**出戏感（反人类读秒时间/扇形统计图眼神/欧美翻译腔）**、**机械套路（瞳孔地震/嘴角勾起弧度/段末命运齿轮升华）**以及**空心水词（毫无画面的抽象形容词堆砌）**。

因此，**DeAI-Novel-zh** 提出了网文专属的**“换水不脱水（保字数、换质感）”**法则：
> **砍掉 AI 的“空心水”（生僻酸词、抽象总结、伪哲理升华），等价换上网文的“实心肉”（大白话具象动作、五感画面、鲜活口语台词、接地气心理拉扯），在消除 AI 痕迹的同时，使章节字数稳定保持在原文的 90%～110%！**

## 🎯 核心精修维度（8 大重灾区 · 28 条实战模式 + 智能分章与黄金钩子）

1. **清剿生僻字与伪文青酸词（零阅读门槛）**
   - 严禁出现让读者“看小说还得查字典”的冷僻字与酸词（如：`氤氲、摩挲、桎梏、诘问、睥睨、嗫嚅、踟蹰、龃龉、藩篱、裹挟、斑驳、嘴角噙着`），全部转化为三岁小孩都能秒懂、画面感极强的大白话。
   - 消灭“某种难以言喻的、某种不可名状的”抽象黑洞词。
2. **修正夸张离谱比喻与强凑排比**
   - 砍掉跨维度的出戏比喻（如在古风/都市里动辄“亿万恒星在脑海引爆”）和烂大街的 AI 机械比喻（“声音像砂纸摩擦”、“眼神像手术刀”、“像断了线的风筝”、“像被掐住脖子的公鸡”）。
   - 打碎 AI 强凑的“三段式排比”与四字成语连环堆砌，还原为有先后顺序的具体动作。
3. **消灭反人类时间感知与游标卡尺式量化**
   - **反人类时间**：“足足呆滞了三秒钟”、“停顿了 0.5 秒”、“万分之一秒内”、“0.01 秒的刹那” → 改为符合人类直觉的“一愣、半晌、眨眼工夫、话音未落”。
   - **扇形统计图与量角器**：“三分薄凉、三分讥诮、四分漫不经心”、“嘴角上扬三十度”、“距离喉咙 0.02 公分” → 改为具体神态与动作压迫感。
4. **整治五官与生理器官“机械成精”**
   - 彻底治理 AI 小说里每页都在做广播体操的五官：**“瞳孔骤缩/地震”、“嘴角勾起一抹邪魅/玩味的弧度”、“喉结上下艰难滚动”、“指节用力到泛白/指甲嵌进肉里”、“后背惊出密密麻麻的冷汗”、“心脏漏跳一拍”**。
5. **剔除欧美翻译腔与理科说明书味**
   - 清除“耸了耸肩，摊开双手”、“哦老天，这太疯狂了”、“该死，你在跟我开玩笑吗”、“大脑飞速运转处理庞大的信息流”、“理智的弦彻底崩断”、“空气中弥漫着名为尴尬的气息”。
6. **撕掉抽象情绪标签，拯救“话剧腔/说明书”台词**
   - 将“他心中涌起难以名状的悲凉与荒谬”转化为具体动作表现（Show, don't Tell）。
   - 将主谓宾俱全的舞台剧朗诵腔、百度百科式路人解说，改写为短促、带语气词、有活人味与身份特征的网文口语台词。
7. **砍掉段末/章末强行升华与“命运齿轮”旁白**
   - 清除段尾爹味说教与章末俗套预告（“命运的齿轮开始转动”、“一场风暴正在黑暗中酝酿”、“这不仅是一场战斗，更是……”），用**黄金断章法**定格在具体动作、狠话或突发悬念画面上。
8. **手机端黄金排版与网文设定白名单保护**
   - **手机端呼吸感分段**：自动拆分 AI 密不透风的 200 字“文字墙”，对话独立成行，爽点转折单列，同时杜绝无意义的“单句回车刷屏”。
   - **网文设定白名单**：严格保护`【系统面板/属性框/弹幕】`、功法境界专有名词、角色专属口癖以及先抑后扬的装逼拉扯节奏，绝不误删。
9. **智能字数监控与黄金断章分章（严格遵循标准网文章节规范）**
   - **标准单章（2000～3000 字）**：符合起点、番茄等平台最黄金的阅读体验，维持单章交付，章末必带悬念钩子。
   - **长章智能拆分（4000～6000 字 → 拆分为两章）**：在不改变原意的前提下，在情节约 2000～3000 字处寻找最佳情绪转折点平滑拆分为 2 章。
   - **超长篇拆分（超过 7000 字 → 拆分为三章）**：按每章 2000～3000 字节奏在关键打脸/悬念处拆分为 3 章（或对应数量）。
   - **每章带钩子（拒绝生硬腰斩）**：**分出来的每一章都严格遵循正常网文章节写作标准**——起承转合结构完整，开篇快速吸睛，中段冲突推进，**每一章末尾都必须带有高诱惑力的黄金断章钩子（Hook）**，让读者迫不及待追读下一章；且各自拟定极具吸引力的全新独立章节名（杜绝“上/下篇”式敷衍命名）。

## 🚀 使用方法

### 1. 安装位置
- **Google Antigravity / Gemini CLI**：将本仓库克隆至 `~/.gemini/config/skills/deai-novel-zh` 或项目工作区的 `.agents/skills/deai-novel-zh`。
- **Claude Code**：将本仓库克隆至 `~/.claude/skills/deai-novel-zh`。

```bash
git clone https://github.com/rpkmhknrcg-star/DeAI-Novel-zh.git ~/.gemini/config/skills/deai-novel-zh
```

### 2. 日常调用示例
直接向 Agent 发送小说草稿或指定章节文件：
- `用 deai-novel-zh 帮我润色下面这章小说，按起点玄幻风去 AI 味，保住字数`
- `帮我把 chapter_05.md 里的 AI 味去掉，字数超了就按网文标准拆成两章，每章都要起好章名并做好章末断章钩子`

### 3. 默认输出规范（纯净直出）
为了方便作者直接复制粘贴到**起点作家助手 / 番茄作家后台**，本 Skill 默认执行**纯净直出模式**：
- 直接输出精修后的完整小说正文（若触发分章，则按 `### 第X章 [新章名]` 分章输出，每章均具备独立起承转合与黄金钩子），不在正文前输出任何寒暄或分析废话。
- 仅在正文最末尾附带 **2～3 行极简修改摘要**（包含字数统计、分章情况与重点清理项）。
